## 🚀 How to Launch

### Option 1: Development Mode (for testing)

```bash
bun run dev
```

Then open: http://localhost:3000

### Option 2: Production Build

```bash
# Build the project
bun run build

# Start production server
bun run start
```

### Option 3: Deploy to Vercel (Recommended)

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel
```

## 🔧 Customization Guide

### To Update Content:

1. **Contact Info**: Edit `components/Location.tsx`
2. **Services**: Edit `components/Services.tsx`
3. **Reviews**: Edit `components/Reviews.tsx`
4. **Colors**: Edit `app/globals.css` CSS variables
5. **Images**: Replace Unsplash URLs in `components/Hero.tsx` and `components/WhyUs.tsx`

### To Add New Sections:

1. Create component in `components/`
2. Import in `app/page.tsx`
3. Add to the page structure
